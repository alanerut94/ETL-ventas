# Proyecto Data Engineer - Ventas con BigQuery

Pipeline ETL que carga datos de ventas desde un archivo CSV a Google BigQuery, ejecuta consultas para identificar las prendas más vendidas y más caras, y exporta los resultados a CSV locales.

## Tecnologías

- Python 3.12
- pandas, pyarrow, pandas-gbq, db-dtypes
- Google Cloud BigQuery
